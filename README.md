# Dados

## `raw/`

- `customer_churn.csv`: base sintética em formato aberto, gerada com seed fixa.
- `customer_churn.xlsx`: versão formatada com tabela, filtros e dicionário de dados.

## `processed/`

- `customer_churn_clean.csv`: base validada e enriquecida com receita anual, receita em risco, faixas de relacionamento, engajamento e score de risco.

Nenhum arquivo contém dados pessoais reais.
